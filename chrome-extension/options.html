Backend settings

Connect your Frappe site

Use your own HTTPS Frappe site URL and a dedicated API key/secret. The token is stored locally in Chrome extension storage and is never sent to any third-party service.

In Frappe, create a dedicated user/API key with only the permissions needed for your trading records. Enter the combined value api_key:api_secret.

Safety

The extension does not store WazirX exchange keys and does not enable live trading. Keep exchange credentials on the Frappe server. The extension's scan action is paper-mode-only.
